# autotest-note

自动化测试学习笔记与实践代码仓库

## 项目简介

这是一个用于分享自动化测试学习笔记和实践代码的仓库，涵盖Web自动化测试、接口测试、测试框架等多个领域。

同时，欢迎关注公众号获取更多原创技术文章。

## 📚 内容结构

```
autotest-note/
├── WebDriverManager源码.py    # WebDriverManager源码学习笔记
├── 必学经典代码-baidu.py       # 百度搜索自动化测试示例
└── README.md                 # 项目说明文档
```

## 🛠️ 技术栈

- **编程语言**: Python 3.x
- **测试框架**: Selenium, pytest
- **浏览器驱动**: WebDriverManager

## 🚀 快速开始

### 环境要求

- Python 3.8+
- 安装依赖:
```bash
pip install selenium webdriver-manager
```

### 运行示例

```bash
# 运行百度搜索自动化测试
python 必学经典代码-baidu.py

# 查看WebDriverManager源码解析
python WebDriverManager源码.py
```
